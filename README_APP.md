# 動画モザイク GUI の使い方

コマンドを打ったり、ペイントで座標を調べたりしなくても、画面上のクリックだけでモザイク処理ができます。

## 起動
1. プロジェクトのフォルダ（`mosaic.py` があるフォルダ）にある **`start_app.bat` をダブルクリック**します。
2. 初回だけ、必要な部品（gradio）を自動でインストールします（数分かかることがあります）。
3. しばらくするとブラウザが開き、「動画モザイク」の画面が表示されます。
   開かない場合は、黒い画面に出ている `http://127.0.0.1:7860` をブラウザで開いてください。

## 作業の流れ
1. **① 動画を読み込む** — 動画ファイルをドラッグ＆ドロップします。解像度・fps・長さが表示されます。
2. **② 開始フレームを選ぶ** — スライダーを動かして離すと、その時刻のフレームが表示されます。対象がはっきり写っている場面を選んでください。
3. **点をクリック** — 「対象」を選んだ状態で、モザイクをかけたい部分をクリックします（緑の点）。
   隣の人など、間違えて含まれやすい部分は「対象じゃない」に切り替えてクリックします（赤い ×）。
   間違えたら「1つ戻す」「全部消す」。
4. **④ オプション** — モザイクの広げ幅・粗さを調整します。「処理する秒数」に例えば `5` と入れると最初の 5 秒だけ処理するので、本番前の試しに便利です（空欄なら動画全体）。
5. **⑤ 実行** — 「モザイク処理を開始」を押すと、進み具合と残り時間が表示されます。途中でやめたいときは「停止」。
6. **確認・保存** — 終わると下に結果の動画が表示され、再生して確認できます。ファイルはプロジェクトのフォルダに `元の名前_out.mp4` として保存されます（プレビューのダウンロードボタンからも保存できます）。

## 途中で指定し直す（再指定）
手などで対象が隠れたり、別の物と重なったりすると、追跡が外れることがあります。
そのときは **③ 途中で対象を指定し直す** を開き、
1. 外れてしまう少し後の時刻（対象がまた見えている場面）にスライダーを合わせて「このフレームを表示」
2. 対象をクリック（必要なら「対象じゃない」も）
3. 「再指定として追加」

を行ってから実行します。その時点で追跡が正しい対象に戻ります。いくつでも追加できます。

## 終了のしかた
ブラウザのタブを閉じたあと、**黒いコマンド画面（start_app.bat の画面）を閉じます**。これでアプリは完全に終了します。

## プライバシー
動画の処理はすべて **このパソコンの中だけ** で行われます。動画がインターネットに送られることはありません
（初回の gradio インストール時だけインターネットを使います）。
