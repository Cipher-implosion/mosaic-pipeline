# 動画モザイク GUI の使い方

コマンドを打ったり、ペイントで座標を調べたりしなくても、画面上のクリックだけでモザイク処理ができます。

## 起動
1. プロジェクトのフォルダ（`mosaic.py` があるフォルダ）にある **`start_app.bat` をダブルクリック**します。
2. 初回だけ、必要な部品（gradio）を自動でインストールします（数分かかることがあります）。
3. しばらくするとブラウザが開き、「動画モザイク」の画面が表示されます。
   開かない場合は、黒い画面に出ている `http://127.0.0.1:7860` をブラウザで開いてください。

## 作業の流れ
1. **① 動画を読み込む** — 動画ファイルをドラッグ＆ドロップします。解像度・fps・長さが表示されます。
2. **② 開始フレームを選ぶ** — スライダーを動かして離すと、その時刻のフレームが表示されます。対象がはっきり写っている場面を選んでください。
3. **点をクリック** — 「対象」を選んだ状態で、モザイクをかけたい部分をクリックします（緑の点）。
   隣の人など、間違えて含まれやすい部分は「対象じゃない」に切り替えてクリックします（赤い ×）。
   間違えたら「1つ戻す」「全部消す」。
4. **④ オプション** — モザイクの広げ幅・粗さを調整します。「処理する秒数」に例えば `5` と入れると最初の 5 秒だけ処理するので、本番前の試しに便利です（空欄なら動画全体）。
5. **⑤ 実行** — 「モザイク処理を開始」を押すと、進み具合と残り時間が表示されます。途中でやめたいときは「停止」。
6. **確認・保存** — 終わると下に結果の動画が表示され、再生して確認できます。ファイルはプロジェクトのフォルダに `元の名前_out.mp4` として保存されます（プレビューのダウンロードボタンからも保存できます）。

## 途中で指定し直す（再指定）
手などで対象が隠れたり、別の物と重なったりすると、追跡が外れることがあります。
そのときは **③ 途中で対象を指定し直す** を開き、
1. 外れてしまう少し後の時刻（対象がまた見えている場面）にスライダーを合わせて「このフレームを表示」
2. 対象をクリック（必要なら「対象じゃない」も）
3. 「再指定として追加」

を行ってから実行します。その時点で追跡が正しい対象に戻ります。いくつでも追加できます。
登録した再指定は「登録済みの再指定」の表にフレーム番号つきで並びます。行をクリックするとそのフレームが表示され、点を直して「再指定として追加／更新」で上書き、「このフレームの再指定を削除」で消せます。

## コマ送りでフレームを正確に選ぶ
②と③のどちらにも、スライダーの下にコマ送りのボタンがあります。
- **◀ −1 ／ +1 ▶**：1 フレームずつ戻る／進む
- **◀◀ −10 ／ +10 ▶▶**：10 フレームずつ戻る／進む
- **フレーム番号** に数字を入れて **ジャンプ**（または Enter）：そのフレームへ移動

画像の上に「フレーム 123 ／ 最後 599（4.100 秒）」のように今のフレーム番号が出ます。スライダーとボタンは連動しています。
点の一覧にも、点を置いたフレームの番号が表示されます。

## 実行中のアラートと完了後の総括
処理中に追跡が外れた、モザイクのかからないフレームが続いている、などが起きると、⑤の **「アラート」** 表にフレーム番号つきでその場で表示され、黄色の警告が出ます。
- おかしいと思ったら **「停止」** を押します。点と再指定は消えずに残ります。
- **アラートの行をクリックすると**、③にそのフレームが表示されます（③は自動で開きます）。結果の動画がある場合は、その隣に結果の同じフレームも表示されます。対象をクリックして「再指定として追加／更新」を押し、もう一度実行してください。

処理が終わると **総括**（モザイクがかからなかったフレームの数と範囲、追跡が外れた回数など）が表示されます。問題のあるフレームがあれば「追加修正で直せます」という警告が出ます。

主なアラートの種類：
| 表示 | 意味 |
|---|---|
| ⚠ 追跡ロスト | 対象を見失った（マスクが小さくなった・消えた） |
| ℹ 追跡復帰 | 見失った対象をまた捉えた |
| ⚠ 自動再捕捉に失敗 | 人物検出で探し直したが戻れなかった |
| ⚠ マスクなしが連続 | 10 フレーム以上、モザイクの形が空のまま |
| ℹ マスク保持 | 「マスク保持フレーム数」の機能で直前のモザイクを残した |
| ⚠ モザイクなし | 完成した動画で、モザイクがかかっていないフレームの範囲 |

## プレビュー実行（冒頭だけ試す）
**「プレビュー実行（冒頭だけ）」** を押すと、動画の最初の N 秒だけを処理します（N は横の「プレビューの秒数」、最初は 30 秒）。
結果は `元の名前_preview.mp4` に保存されるので、本番の出力（`_out.mp4`）は上書きされません。
点の位置やオプションが良さそうか確かめてから、「モザイク処理を開始」で全体を処理してください。
※ 開始フレームがプレビューの範囲より後ろにあるとエラーになります。秒数を増やしてください。

## 完成した動画を追加修正する
**修正は出力済み動画にモザイクを重ねる方式です。** 一度処理した結果にモザイクの漏れがあったとき、最初からやり直さずに、漏れた部分にだけモザイクを足せます。
1. 処理が終わったら **「この結果を追加修正する（結果を入力に読み込む）」** を押します（または①で「処理の種類」を **追加修正** にして、`_out.mp4` などの出力済み動画を読み込みます）。
2. 漏れたフレームへ移動します（アラートの行をクリックする、またはコマ送り）。
3. ②の開始フレームをそのフレームにして対象をクリックします（必要なら③で再指定も追加）。
4. 「モザイク処理を開始」を押すと、`元の名前_fix.mp4` が新しく作られます。もう一度直すと `_fix2.mp4`、`_fix3.mp4` … と番号が増えます。

読み込んだ動画は上書きしません。すでにモザイクがかかっている部分にもう一度モザイクが重なるだけなので、見た目はほぼ変わりません。

## 途中修正について
処理を動かしたまま途中で指定を足すことはできません。おかしいと思ったら「停止」し、アラートのフレームで再指定を追加してから、もう一度実行してください（プレビュー実行で冒頭を試すのも便利です）。

## 終了のしかた
ブラウザのタブを閉じたあと、**黒いコマンド画面（start_app.bat の画面）を閉じます**。これでアプリは完全に終了します。

## プライバシー
動画の処理はすべて **このパソコンの中だけ** で行われます。動画がインターネットに送られることはありません
（初回の gradio インストール時だけインターネットを使います）。
